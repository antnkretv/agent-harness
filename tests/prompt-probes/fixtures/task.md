# Ожидание блокировки в with-file-lock.py не ограничено

## Проблема

Установка инструментов агента идет под блокировкой `with-file-lock.py`. Если первая сессия зависла
на скачивании пакета, вторая ждет ее без предела и не узнает, кто держит блокировку.

## Что сделать

1. Ожидание блокировки ограничено ключом `--timeout` в секундах; по истечении скрипт выходит с кодом 2.
2. Сообщение об истечении называет pid процесса, который держит блокировку.
3. Держатель называется и на Windows.

## Критерии приемки

- Второй процесс с `--timeout 1` при занятой блокировке выходит с кодом 2 за 1-2 с.
- Сообщение содержит pid держателя.
- Без `--timeout` поведение прежнее: ожидание до освобождения.
