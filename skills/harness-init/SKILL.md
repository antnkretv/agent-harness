# Установка harness

Скилл - вход из чата в процедуру `AGENT.md` комплекта. Порядок, коды и критерии готовности - там.
Агент выполняет его из каталога `skills/` распакованного архива: скилл никуда не копируется.
На Windows выполняй ее из Git Bash в Git for Windows с Windows Python и поставляемым `python.cmd`;
`configure` с ответом, начинающимся с `/`, - с префиксом `MSYS_NO_PATHCONV=1 MSYS2_ARG_CONV_EXCL='*'` в строке
команды, а не в окружении сессии (`AGENT.md`, начало).

## 1. Архив

Путь к архиву `agent-harness-<версия>.tar.gz` или `agent-harness-<версия>-<решения>.tar.gz` и его
sha256 - аргументы вызова. Чего нет - спроси владельца одним вопросом; архив по диску не угадывай.

## 2. Комплект

```bash
sha256sum <архив>                                   # не совпало с данным sha256 - стоп
KIT="$HOME/.cache/harness/$(basename <архив> .tar.gz)"
rm -rf "$KIT" && mkdir -p "$HOME/.cache/harness" && tar -xzf <архив> -C "$HOME/.cache/harness"
```

Каталог распаковки лежит вне репозитория проекта.

## 3. Процедура

Прочитай целиком `$KIT/AGENT.md` и `$KIT/installer/stages/STAGE-1.md` и иди по `STAGE-1.md` с раздела
"Обследовать проект" до раздела "PR накатки" включительно, не пропуская шагов. Этап не завершен, пока
каждый пункт этапа 1 в разделе "Критерии готовности" `AGENT.md` не подтвержден выводом его команды.
Отказ `doctor` по инструменту снимает скрипт раздела "Зависимости", отказ доступа и Python - действие
владельца, случай 1 раздела "Когда этап останавливается" `AGENT.md`: назови строку и жди владельца. Этапы 2 и 3 идут отдельными сессиями по `STAGE-2.md` и
`STAGE-3.md`.

## 4. Итог

Отчет этапа 1 по шаблону раздела "Отчет" `AGENT.md`.
