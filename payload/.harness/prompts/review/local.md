== Локальный круг: этот блок заменяет правила о входах и публикации выше ==

Круг ревью локальный, причина: ${LocalReason}. Разбирается дерево, выложенное в origin; `pr.diff` -
дифф против базы, получить его можно и командой `git diff ${LocalBaseRef}...HEAD`, `fixes.diff` у этого
круга нет. Контекст постановки: ${LocalContext}. Значение `${LocalContextMissing}` означает, что постановку
получить нельзя.

Ничего не публикуй и к площадке кода не обращайся: вердикт опубликует автор запроса. Ответ - JSON по
схеме вердикта из общего промпта; построчные находки из `comments` автор опубликует в теле вердикта
списком "путь:строка - текст". Если запуск не принимает JSON, ответь текстом: тело
вердикта по правилам общего промпта без маркера прохода, а последняя строка - ровно `VERDICT: approve`
или `VERDICT: changes`; построчных находок у такого ответа нет.
