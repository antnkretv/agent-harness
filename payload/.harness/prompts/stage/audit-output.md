Итог независимого аудита процесса верни одним объектом JSON по схеме ниже, без текста вокруг него. verdict - approve при отсутствии блокирующих находок, changes при находках, blocked если разбор не состоялся из-за отказа среды или инструментов. body обязательно описывает изученные свидетельства, выполненные проверки и оставшиеся ограничения даже при approve без находок. Не подменяй свидетельства отметкой о завершении и не придумывай находки ради непустого тела. comments - подтвержденные находки к строкам: path от корня репозитория, line - номер строки, side - RIGHT для строки новой версии файла и LEFT для удаленной строки базы, body - текст находки; при отсутствии находок comments пуст. Строку VERDICT добавит конвейер из поля verdict.
