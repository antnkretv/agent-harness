Шаг ${StepKey} (${StepDoc}): открой черновой PR в ${BaseBranch}; номер PR за веткой конвейер запишет сам на следующем шаге.
Описание собери по шагам ниже. С задачей добавь к команде сборки --issue <задача>, а если приемка задачи продолжается после PR - --refs <задача>.
Правленое описание собери той же командой с --change <номер> из заполненной заготовки - сохраненной или новой с перенесенными разделами. Статистику сессии и все, что стоит после маркера описания, команда перенесет без изменений, а пустую запись своей сессии, собранную без журнала, посчитает заново. Строки связи с задачей она перенесет, если не заданы --issue и --refs; с ними строки связи задают только они.
