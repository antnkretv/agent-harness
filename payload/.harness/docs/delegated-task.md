# Постановка исполнителю

> **Тип (Diataxis):** Справочник

Шаблон задания, которое координатор передает агенту-исполнителю. Раздел, которого задача не
касается, опускается. Если раздел относится к задаче, но по решению координатора пуст, например
новых тестов не нужно, он называет причину.

## Разделы

| Раздел | Что содержит |
| --- | --- |
| База | SHA, на котором написана постановка, и команда проверки сдвига: `git diff <SHA>..origin/<база> -- <пути постановки>`. При сдвиге исполнитель до начала работы называет устаревшие пункты |
| Цель и тема | Наблюдаемый результат и одна тема PR; попутные правки - только по политике `agents.findings` |
| Инварианты | Поведение, которое нельзя ослабить, и текущий исполнитель каждого: гейт, хук, проверка, проход ревью. Сохранность доказывается пробой, а не совпадением со снимком |
| Что снимается | Каждое снятие с заменой или с причиной; снятие проверки ради универсальности или единого источника истины не задается |
| Охват | Дифф или весь корпус для каждого гейта; потребители: установленные проекты, адаптеры поставщика кода и трекера, внешние сниппеты окружения; путь их обновления |
| Приемка | Положительные пробы и пробы, которые должны падать и до правки, и после нее |
| Команды | Команды проверок, которые координатор запустил на базе постановки |
| Тесты | Какие сценарии добавить по [критерию полезности теста](../standards/test-usefulness.md) |
| Источники | Ссылки на правило, поле манифеста или документ вместо пересказа; постановка не требует повторять один факт в двух файлах |
| Решение и предложение | Подсказки реализации помечены как предложение, которое исполнитель проверяет по коду и правилам |
| Очередь | Зависимые постановки и их порядок: постановки, которые меняют одну область, не идут параллельно |
| Размер и стек | Оценка размера против `policies.size` и деление на PR стека, если предел превышен |

## Ответ

Постановка заканчивается требованием к ответу исполнителя: чем закрыт каждый пункт, чем заменено
снятое, какой проверкой подтверждено каждое утверждение и что осталось. Исполнитель заполняет слоты
заготовки `text_templates.py form DelegatedReport --out <файл>` и собирает ответ командой
`text_templates.py render report/delegated --set-file DelegatedReport=<файл>`.
