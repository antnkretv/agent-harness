# Документы harness

Правила, процессы и справочники комплекта harness: одинаковы во всех проектах на нем, ставятся
`python3 .harness/ah.py install` и обновляются только новой версией комплекта. Документы проекта,
в том числе стандарты, полученные заготовкой при установке, перечисляет
[`docs/README.md`](../../docs/README.md) проекта.
